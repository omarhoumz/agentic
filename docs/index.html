agentic — multi-account manager for Codex and Cursor Agent CLI

0.1.1

01 What it is

Codex and Cursor Agent accounts on one machine, without them invalidating each other.

Each CLI assumes one account. agentic gives each account its own directory under ~/.agentic/<provider>/ and makes the live auth.json a symlink into the active one.

Coming from codex-accounts? agentic migrate copies ~/.codex-accounts into ~/.agentic/codex.

02 Install

Homebrew

$ brew install omarhoumz/tap/agentic

$ agentic --version

agentic 0.1.1

Same CLI for Cursor Agent accounts — use provider cursor (always with AGENT_CLI_CREDENTIAL_STORE=file, which agentic login / shell-init set for you):

$ agentic login cursor personal

03 Quickstart

Four commands, in this order

  1. $ agentic login codex personal

  2. $ agentic login codex work

    Sign out of ChatGPT in the browser first, or this re-authorises the same account.

  3. $ agentic use codex personal

  4. $ agentic shell-init

    Optional, recommended. Adds a shell function that stops a bare codex login from overwriting whichever account is active — how that happens. After it, the login is redirected:

    $ codex login

    codex login is managed by agentic. Try: agentic login codex <name>

Then check what you have

$ agentic list

codex:
  personal
* work

cursor:
  personal

04 Why it exists

Two accounts can break at once, silently

Every login rotates the account's refresh token and retires the previous one. A copied credential goes stale.

A bare codex login writes through the active link: one command puts the wrong identity under one name and retires the token stored under the other.
